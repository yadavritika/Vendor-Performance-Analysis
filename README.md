#Vendor Performance Analysis

Project Overview

This project focuses on analyzing vendor performance to understand sales, purchases, profitability, and inventory efficiency. The dashboard helps identify high-performing vendors, evaluate profit margins, and analyze capital tied up in unsold inventory.

Tools Used

- Python
- SQL
- Power BI
- Excel
- Data Cleaning and Data Visualization

Dashboard Features

KPI Cards

- Total Sales: Overall sales generated.
- Total Purchase: Total purchase value.
- Gross Profit: Profit earned after deducting the cost of goods sold.
- Profit Margin: Percentage of sales retained as gross profit.
- Unsold Capital: Capital invested in inventory that remains unsold.

Visualizations

- Vendor-wise sales and purchase analysis.
- Gross profit and profit margin comparison.
- Identification of top-performing vendors.
- Analysis of unsold inventory and tied-up capital.
- Comparison of vendor profitability and performance.

Interactive Filters

- Vendor selection.
- Product or brand categories.
- Other available business dimensions in the dataset.

Key Insights

- Identified vendors contributing significantly to total sales.
- Compared purchase costs and sales to evaluate profitability.
- Analyzed differences in gross profit and profit margins across vendors.
- Examined unsold inventory to understand blocked working capital.
- Identified opportunities to improve inventory management and vendor selection.

Skills Demonstrated

- Data Cleaning and Preparation
- Exploratory Data Analysis (EDA)
- SQL Querying
- Power BI Dashboard Development
- DAX Measures and KPI Creation
- Data Visualization
- Business Performance Analysis
- Data-Driven Decision Making

Project Outcome

This project demonstrates how data analysis can help businesses evaluate vendor performance, monitor profitability, manage inventory, and make better purchasing decisions.
